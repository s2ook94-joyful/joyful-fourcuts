기쁨네컷 6장 촬영 → 4장 선택 → QR 다운로드

중요: ZIP을 Netlify Drop으로 올리면 6장 촬영/4장 선택/직접 저장은 작동하지만 QR 공유용 Netlify Functions는 작동하지 않을 수 있습니다. QR까지 사용하려면 GitHub 저장소에 이 파일들을 업로드하고 Netlify에서 Git 연동으로 배포해야 합니다. Netlify가 npm 의존성(@netlify/blobs)을 설치하고 Functions를 배포해야 QR이 동작합니다.

QR 사진은 업로드 시점부터 24시간 후 링크가 만료되며, 만료된 사진은 링크를 다시 방문할 때 삭제됩니다. 자동 주기 삭제 기능은 별도로 설정해야 합니다. QR 링크를 아는 누구나 사진에 접근할 수 있습니다.

현재 관리자 비밀번호는 1234로 브라우저 코드에 공개되어 있어 보안용으로 사용할 수 없습니다.
